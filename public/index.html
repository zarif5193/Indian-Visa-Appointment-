কিভাবে কাজ করে?

চারটা সহজ ধাপ — আপনার মোবাইল থেকেই

1

তথ্য দিন & ডকুমেন্ট আপলোড

Personal, passport, visa তথ্য, ছবি ও passport scan দিন। Center ও preferred date select করুন।

2

bKash-এ payment

Service charge + appointment fee আমাদের bKash নম্বরে Send Money করুন, Transaction ID submit করুন।

3

Verification

আমরা payment ও ডকুমেন্ট verify করি। কোনো সংশোধন লাগলে website-তেই জানাব — আপনার জন্য correction form থাকবে।

4

Booking & Receipt

Appointment booking হয়ে গেলে receipt PDF আপনি status page থেকে নিতে পারবেন।

দুঃখিত, এই মুহূর্তে নতুন application accept করা হচ্ছে না। কিছু দিন পর আবার চেষ্টা করুন।
✅

Application submitted!

আপনার application ID নিচের মতো — এটা ভালোভাবে সংরক্ষণ করুন।

এখন যা করবেন:
  1. আমাদের bKash নম্বরে Send Money করুন।
  2. Payment-এর পর Application Status পেজে গিয়ে Transaction ID submit করুন*।
  3. Mobile number সচল রাখুন — booking-এর সময় OTP দরকার হতে পারে।

* Transaction ID application form-এর payment ধাপে দিলেই যথেষ্ট। Status page দিয়ে পরেও সংশোধন করা যাবে।
